# Lock-Buch

Eine selbstgebaute, komplett offline laufende Web-App zum Tracking einer Keyholder/Sub-Dynamik (D/S). Läuft direkt im Browser als einzelne HTML-Datei — keine Installation, keine Cloud, keine Anmeldung, keine Server. Alle Daten bleiben lokal bei euch.

## Funktionen

- **Heute** – täglicher Überblick über Stimmung, Käfig-Status, Ritual-Checkliste u.v.m.
- **Kalender** – Verlauf, Serien-Tracking, automatische Auszeichnungen
- **D/S** – Regeln, Ziele, Rituale, Dankbarkeitsnotizen, Käfig-Gewöhnung mit Verschlusszeitrechner
- **Training** – Trainingspläne mit flexiblen Kategorien, Wochenplan mit Mehrfachbelegung
- **Strafbuch** – Protokoll von Verfehlungen und Konsequenzen
- **Lucky Sub** – Glücksrad, Würfel, Cum-down, Medaillenschrank, Ideenkiste, Melkzähler u.a.
- **Neigungsbogen** – ausführlicher Fragebogen mit Blind-Bewertung und automatischem Abgleich
- **Austausch** – Export/Import zur Synchronisation zwischen zwei Geräten
- **Sicherheit** – Zugangsverwaltung, Safeword, Notfallkontakt

## Nutzung

1. `lockbuch76.html` herunterladen
2. Datei im Browser öffnen (Chrome/Edge empfohlen — manche Funktionen wie Spracheingabe brauchen die Web-Speech-API)
3. Beim ersten Öffnen: Passwörter für beide Rollen (Keyholder/Sub) festlegen

Zur Synchronisation zwischen zwei Geräten: im Tab „Austausch" exportieren/importieren.
